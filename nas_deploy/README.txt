このパッケージは、Synology NAS 上で完全自立ホスティングし、
伝熱工学・特許計算式を外部に1ミリも漏らさずに安全にWebシミュレーターを
公開するためのスタンドアロン版プログラム一式です。

【含まれるファイル】
・server.cjs  : 特許計算エンジン内蔵サーバー（外部ライブラリ不要・単体動作）
・dist/       : シミュレーターのWeb画面（HTML / CSS / JS / 各種ロゴ）
・start.sh    : NAS用ワンクリック起動スクリプト

----------------------------------------------------------------------
■ 手順1: NASに「Node.js」をインストール
----------------------------------------------------------------------
1. Synology DSM（NAS管理画面）にブラウザでログインします。
2. 「パッケージセンター」を開きます。
3. 検索バーに「Node.js」と入力し、「Node.js v18」または「Node.js v20」を
   インストールします（無料・クリックのみで完了）。

----------------------------------------------------------------------
■ 手順2: ファイルをNASにコピー
----------------------------------------------------------------------
1. DSMの「File Station」を開きます。
2. 共有フォルダ（例: web フォルダ内、または任意の共有フォルダ）に
   「chiller」という新しいフォルダを作成します。
3. このZIPを展開した中身（server.cjs、start.sh、distフォルダ）を
   すべてその「chiller」フォルダ内にアップロードします。

----------------------------------------------------------------------
■ 手順3: 起動
----------------------------------------------------------------------
【方法A: タスクスケジューラーを使う（推奨・NAS起動時に自動実行）】
1. DSMの「コントロールパネル」＞「タスクスケジューラー」を開きます。
2. 「作成」＞「トリガされたタスク」＞「ユーザー定義のスクリプト」をクリック。
3. タスク名: QuliyaChiller / イベント: 起動時
4. 「タスク設定」タブの「ユーザー定義のスクリプト」欄に以下を入力:
   cd /volume1/web/chiller && node server.cjs
   （※フォルダの場所に合わせてパスを指定してください）
5. 「OK」を押し、タスクを選択して「実行」ボタンを押します。

【方法B: SSHターミナルを使う】
NASにSSH接続し、該当ディレクトリで以下を実行します:
$ node server.cjs

----------------------------------------------------------------------
■ 手順4: ブラウザでアクセス
----------------------------------------------------------------------
・社内/学内LANから: http://[NASのIPアドレス]:3000
・外出先/関係者様から: http://[SynologyのDDNS名].synology.me:3000
  （※DSMの「コントロールパネル」＞「外部アクセス」＞「DDNS」で無料作成可能）
・リバースプロキシ（DSM「ログインポータル」＞「詳細」）を設定すれば、
  https://chiller.synology.me などの標準HTTPS (443ポート) でも公開可能です。

★ 特筆事項（完全秘匿セキュリティ）：
・計算式やパラメータはすべて server.cjs 内でのみ実行されます。
・アクセスしたユーザーのPCにはグラフ結果データしか届かないため、
  Gemini等のAIにどれだけ解析させても、特許数式や定数は絶対に特定されません。
